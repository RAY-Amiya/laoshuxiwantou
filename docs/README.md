# CRTC2026 备赛文档 · 总入口

> 队伍：`老鼠洗完头`　队长：`岳楷清`　仓库：`https://github.com/RAY-Amiya/laoshuxiwantou`　最后更新：`2026-10-17`

本目录是 CRTC2026 中期考核的**文档评估**材料。按手册要求：所有文档置于仓库根目录的 `docs/` 文件夹内，以 markdown 提交，**以单个机器人功能为一个板块**（H2 标题 + 功能描述与开发历程），并按设计进度完成时间点从早到晚组织。

> **⚠ 方案演进提示（先看这一条，再往下看）**
> 机械方案前后经历五次转向，**最终口径以 2026-10-16 归档的 V8 为准**：
> 1. **V1 → V3.2（10-01 ~ 10-05）**：滚刷拨送收料路线，**已废弃**（现无收料辊）。
> 2. **10-11（中间决策，已被取代）**：曾定「两台完全同构的举升取核车（V4 平台复制两台）」。V4 现已**降级为可用备用平台**。
> 3. **10-13**：2 号车转**三爪转盘机械臂**（V5 同步带 → V6 大扭矩舵机 → V7 现有 MG996R 适配版）。
> 4. **10-14**：参赛分组确认为**新生组**；**1 号车与 2 号车完全同构，两台都是三爪机械臂车**。一套设计做两台，模型 / 打印件 / 齿轮 / 固件 / 备件全共用。
> 5. **10-16（现行定案，最终版）**：机械结构升级为 **[V8 最终版整车](02-机械结构日志-V1到V8.md)**——紧凑底盘（220 / 轴距 160）、底盘与机械臂加强一体、独立可拆盖电控盒、L 形储仓、肩 / 肘 / 腕三关节（同平面俯仰）；**全臂传动从模数 1 打印齿轮（肩 22T→28T / 肘 24T→40T / 转盘 52T→20T）改为舵机舵盘直驱**，**三工位转盘随之整个取消**（减重），**三只爪保留、一次仍带 3 块，换位改由腕关节承担**；**取消对 V4 底盘的全部继承**。两台同构的结论不变。
>
> **几条必须知道的细节**
> - 机械部分 **V1 → V8** 的完整演进（含每一次被否决的方案与理由）见 **[02-机械结构日志-V1到V8.md](02-机械结构日志-V1到V8.md)**，V8 的 Fusion 归档与渲染图在 `docs/assets/02-机械结构日志/`。
> - V5/V6/V7 三版演进连同**自研自打印的三指机械爪**已全部并入 02，**不再单建 `05-机械臂结构日志-V5.md`**。
> - **[04-电控与运动学.md](04-电控与运动学.md) 的实际内容**是整车共用底座电控（STM32 + FreeRTOS 任务划分 / DRV8833 驱动与过流保护 / PS2 手柄接入），**不含机械臂逆解**。机械臂侧电控已独立成 **[05-机械臂电控.md](05-机械臂电控.md)**（2026-10-14 新建）：6 路 PWM 资源与引脚分配 / 关节限位与脉宽标定 / 平面 2 连杆闭式逆解与腕关节换位 / 舵机供电与浪涌 / 动作状态机 / 安全与故障 / 调试计划。
> - **[99-开源项目说明.md](99-开源项目说明.md)** 已在 2026-10-14 完成核实（登记 3 条：2 个机械臂控制类参考仓库 + `FreeRTOS-Kernel`；项目 1 的源码逐文件读完，项目 2 只登记仓库不固定版本）。
> - **新生组的物资规则与其它组不同**：手册规定官方物资表"仅作为理论培训时使用的套件，具体使用的物资（不得违犯机器人制作规范）**由参赛队伍自行决定**"。因此 MG996R / MG90S / 625 轴承 / Ø5 钢轴 / 轴环 / 垫片等**表外件均可自购**；但**通用技术规范仍全部适用**（每台仅 1 个供电模块、额定电压 ≤ 7.4 V、尺寸 / 重量 / 落体 / 安全）。
> - **`03` 记录到 V7 为止的机构设计与取舍**（肩 / 肘 / 转盘 / 三指爪 / 前置储仓各自的选型对比、遇到的问题与迭代）；**V8 对全臂做的整车改动（齿轮改舵盘、取消转盘、加腕关节、换紧凑底盘）记在 `02` 的 V8 板块里**，两者冲突处以 V8 为准。

## 三、每个板块的统一写法

每个 H2 板块严格按下面 7 节展开。第 3、5、6 节是拉开档次的**关键三节**，不可省略。

| 节 | 标题 | 要求 |
|---|---|---|
| 1 | 目标与验收标准 | 要达成什么 + 手册里对应哪条指标 + 量化验收表（目标值 / 实测值 / 结论） |
| 2 | 初版构思 | 第一版想法、关键假设、风险预判（鼓励画草图、贴手绘照片） |
| 3 | **技术选型对比** | 表格：候选方案 / 优点 / 缺点 / 关键数据 / 结论。**必须写明"为什么选它"**，不是罗列所有方案 |
| 4 | 实现过程 | 机械（尺寸、材料、加工、装配顺序）+ 电路（模块、接口、供电）+ 代码（文件路径 + 关键代码块）+ 关键参数表 |
| 5 | **遇到的问题与解决** | 每个问题按「现象 → **定位过程** → 根因 → 对策 → 验证结果」写。**定位过程**最值分：怎么一步步缩小范围的？测了什么、排除了什么？ |
| 6 | **迭代优化** | 表格：版本 / 改动 / 为什么改 / 指标变化（带数据）/ 代价 |
| 7 | 当前状态与遗留 | 已完成 / 未完成与风险 / 下一步 |

## 四、写作规范

- 长度：每节 1 段（含表格）即可，不要灌水；但**结论必须有数据支撑**（尺寸 mm、重量 g、行程 mm、耗时 s、成功率 %）。
- 术语：功能名称、指标名称与手册保持一致（如「能量单元」「能量核心」「携带」「收集」）。
- 数字与单位：数值与单位之间加空格（`290 mm`、`2.0 kg`、`150 mm`），单位统一用毫米/克/秒。
- 图片命名：`<功能名>-<内容>-<版本>.<扩展名>`，例：`roller-intake-v2-topview.jpg`。
- 代码：只贴关键片段（10~30 行），完整代码放 `firmware/`，在文档里给出路径。
- 开源：凡是用到的库、PCB 设计、CAD、参考代码，都要在 [99-开源项目说明.md](99-开源项目说明.md) 里登记。
