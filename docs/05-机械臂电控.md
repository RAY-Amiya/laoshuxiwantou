> 对应机器人：**1 号车 与 2 号车（两台完全同构，均为 V8 三爪机械臂车）**　｜　本文件承载的 H2 板块：**舵机资源与引脚分配**、**关节编号与限位标定**、**角度映射与脉宽标定**、**逆解与腕关节换位**、**舵机供电与浪涌**、**动作序列与状态机**、**安全与故障处理**、**调试与验证计划**

**本文件与 `04-电控与运动学.md` 的边界**：04 管**整车共用**的电控底座（STM32 + FreeRTOS 任务划分、DRV8833 底盘驱动与过流保护、PS2 手柄接入）；本文件只管**机械臂这一套舵机系统**——资源分配、标定、逆解、供电、动作时序与安全。凡是两处都要用的结论（例如"舵机 PWM 与电机 PWM 必须分定时器"），以 04 为准，本文件只引用不重复论证。

**⚠ 口径版本（2026-10-17 按 V8 审核）**：本文件的**引脚与资源分配仍按 V7 编排**，但机械结构已于 2026-10-16 升级为 **V8（整车重做）**。V8 对本文件的影响集中在五件事，正文已按 V8 修订，原 V7 口径保留在各自小节里并明确标注为历史：

## 舵机资源与引脚分配

> 完成时间点：2026-10-12　｜　状态：**已定**

### 1. 目标与验收标准

一块 **STM32F103C8T6**（LQFP48，只有 PA/PB 两组口）要同时驱动：

- **4 个底盘电机**（TT 马达 ×4，经 4 片 DRV8833，每片 1 路 PWM + 1 路方向）
- **6 个舵机**（3× MG996R 180° 管 **肩 / 肘 / 腕**，3× MG90S 管三只夹爪）——**V7 的第 3 路是转盘，V8 起改为腕**
- **PS2 手柄**（**GPIO 位模拟**，4 线：CS / CLK / DAT / CMD，不占 SPI1）
- **调试串口**（USART1）
- **SWD 下载口**（必须保留，否则烧不进程序）

| 手册指标     | 手册要求                                               | 本队验收方式                                  |
| -------- | -------------------------------------------------- | --------------------------------------- |
| 舵机运动（多项） | **同一台机器人完成至少三个舵机的转动**，且**确保其可动机构能在任意非初始状态下保持相对静止** | 6 个舵机全部单轴可动；断电后手动掰动检查——**位置舵机自锁，机构不下坠** |
| 电机运动（全部） | ≥ 4 个电机转动                                          | 4 个 TT 马达分别正反转                          |
| 底盘运动     | 用 PS2 控制底盘水平运动                                     | 麦轮四轮解算后平移/旋转                            |

> 「**任意非初始状态保持相对静止**」这一条是**规则层面锁死"必须用位置舵机"**的原因：普通直流减速电机断电即自由转动，做不到；补救手段（蜗轮蜗杆自锁、电磁抱闸）都不在官方物资表内。详见 `04-电控与运动学.md` 与 `99-开源项目说明.md` 里的选型讨论。

### 2. 硬件盘点：定时器与引脚到底够不够

STM32F103C8T6 有 **TIM1 / TIM2 / TIM3 / TIM4** 四个定时器，每个 **4 个通道**。

| 需求       | 通道数 | 频率要求                       | 能否与别的负载共用一个定时器                           |
| -------- | --- | -------------------------- | ---------------------------------------- |
| 底盘电机 PWM | 4   | **约 20 kHz**（要避开可听噪声，且不能抖） | ❌ **不能与舵机共用**——舵机要 50 Hz，改任何一个的频率都会扰动另一个 |
| 舵机 PWM   | 6   | **50 Hz**（周期 20 ms）        | 可以，但**一个定时器最多 4 路**，6 路必须拆到两个定时器         |

**结论：至少需要 3 个定时器**（1 个给电机 + 2 个给舵机），而 C8T6 正好有 4 个。**不需要 PWM 扩展板**——这与 V7 源文件「按用户确认有足够引脚，不新增 PWM 扩展板」一致。

但**引脚复用会打架**，必须提前排掉：

| 冲突                        | 冲突双方                                      | 后果                                                  |
| ------------------------- | ----------------------------------------- | --------------------------------------------------- |
| **PA6 / PA7**             | DRV8833 方向脚（PA4–PA7）ｘ `TIM3_CH1/CH2`（TIM3 默认引脚） | 若舵机占 TIM3 默认脚，**方向脚就没地方放**                          |
| **PA9 / PA10**            | `USART1`（printf 调试）ｘ `TIM1_CH2/CH3`       | 若舵机占这两脚，**调试串口就没了**                                 |
| **PA13 / PA14**           | `SWD`（下载口）                                | 谁占谁砖，**绝对不能用**                                      |
| **PA0 / PA1 / PA2 / PA3** | `TIM2_CH1–4` ｘ `USART2`                   | 用 TIM2 就必须放弃 USART2（本项目不用它，可接受）                     |
| **PB3 / PB4**             | `JTDO` / `NJTRST`（JTAG）                   | 默认被 JTAG 占着，**必须先关 JTAG、只留 SWD**才能当普通 IO / TIM3_CH1 |

### 3. 技术选型对比

**舵机走哪两个定时器？**（这是本节唯一需要权衡的地方）

| 候选                              | 优点                                                                                                     | 缺点                                                                                                                 | 结论       |
| ------------------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ | -------- |
| **TIM2（3 路） + TIM3 部分重映射（3 路）** | ① 6 路一次性解决；② TIM3 部分重映射把 CH1/CH2 从 **PA6/PA7 挪到 PB4/PB5**，把 **PA6/PA7 让给 DRV8833 方向脚**；③ 两个定时器都空着，不碰 USART1 与 SWD | 需在初始化里**禁用 JTAG、保留 SWD**（否则 PB4 不可用）                                                                               | ✅ **采用** |
| TIM3（默认脚，4 路） + TIM1（2 路）       | 不用重映射                                                                                                  | ① TIM3 默认脚 PA6/PA7 **与 DRV8833 方向脚（PA4–PA7）直接冲突**；② TIM1_CH2/CH3 是 PA9/PA10，**与调试串口冲突**；③ TIM1 是高级定时器，配 PWM 还要处理刹车/死区，徒增复杂度 | ❌ 不采用    |
| 用一个定时器 + 软件轮询模拟多路 PWM           | 省定时器                                                                                                   | 6 路 50 Hz 软件 PWM 会**占掉大量 CPU 与中断**，且抖动大；舵机对脉宽抖动敏感                                                                  | ❌ 不采用    |

**电机走哪个定时器？** TIM1 被串口/下载口掣肘、TIM2 与 TIM3 给了舵机，**只剩 TIM4**（PB6–PB9），且这四个脚不与任何外设冲突。✅

| 功能                | 外设/定时器           | 引脚                                      | 参数                          | 备注                                      |
| ----------------- | ---------------- | --------------------------------------- | --------------------------- | --------------------------------------- |

| 底盘电机方向 ×4         | GPIO 输出          | **PA4 / PA5 / PA6 / PA7**               | —                           | 每路 1 个 DIR；**刻意避开 PA0–PA3 与 PB12–PB15**   |

| **MG996R 肩**      | TIM2 CH1         | **PA0**                                 | 50 Hz                       | 负载最大，见「舵机供电与浪涌」                         |
| **MG996R 肘**      | TIM2 CH2         | **PA1**                                 | 50 Hz                       |                                         |
| **MG996R 腕**（V7 为转盘） | TIM2 CH3         | **PA2**                                 | 50 Hz                       | V8 起此路驱**腕关节**（俯仰）；TIM2_CH4（PA3）留作备用     |

> ✅ **接口方式已定（2026-10-17）**：PS2 走**普通 GPIO 位模拟**（PB12–PB15），不占 SPI1；DRV8833 方向脚相应放在 **PA4–PA7**。这两条与 `04-电控与运动学.md` 的 PS2 小节完全一致。
>
> ⚠ **仍需装车前逐脚核对的一条历史记录**：参考工程的 `motor.h` 里留过一条注释——「虽然也是 TIM2 的通道，试过走硬件 PWM，在本车实测不通，已回退」，原因是**那台车的 PA0–PA3 同时被 DRV8833 方向脚（普通 GPIO）占用**。本表把 **PA0–PA3 全部给 TIM2 舵机、方向脚放在 PA4–PA7**，前提不同，所以那条结论**不套用**；但它指出的风险是真的：**一旦方向脚落到 PA0–PA3，TIM2 舵机方案立即失效**，肩 / 肘 / 腕三路须整体改走「TIM3 四路 + TIM1 两路」。**V8 上重新分配引脚的代价更高**（6 路里第 3 路已是腕）。
**定时器参数（两个舵机定时器相同）**：`PSC = 71`（72 MHz / 72 = **1 MHz**，即 **1 count = 1 µs**）、`ARR = 19999`（周期 **20 ms = 50 Hz**）。

→ 由此得到一个非常有用的换算：**比较值 `CCR` 直接就是微秒脉宽**，写 `__HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, 1500)` 就是 1500 µs 中位。标定时不需要再做任何换算。

> 这一条与我们读过的参考项目一致：它的 TIM2/TIM3 同样是 `PSC=71 / ARR=19999`，`pulse_N` 也是直接当 µs 用。注意它 `servo.c` 里那段「PSC = 72-1，ARR = 200-1」的注释**与它自己的代码不符**，是没更新的旧注释——**我们不要照抄注释，只看寄存器值**。

**初始化顺序（有前后依赖，不能颠倒）**：

1. `HAL_Init()` → 时钟树（72 MHz）
2. **关闭 JTAG、保留 SWD**：`__HAL_RCC_AFIO_CLK_ENABLE()` + `__HAL_AFIO_REMAP_SWJ_NOJTAG()` ——**必须在配置 PB3/PB4 之前做**，否则这两个脚无效
3. GPIO 时钟（GPIOA/GPIOB）→ TIM2/TIM3/TIM4 时钟 → USART1（**不含 SPI1：PS2 走位模拟，SPI1 全程不用**）
4. TIM2 / TIM3 按 `PSC=71, ARR=19999` 初始化并**使能对应通道**（注意：TIM3 要先 `__HAL_AFIO_REMAP_TIM3_PARTIAL()`）
5. TIM4 按 `PSC=0, ARR=3599` 初始化
6. 舵机全部先写**中位脉宽**再启动 PWM —— 避免上电瞬间舵机猛甩

**V8 对这张表的四点改写**：

1. **J3 从「转盘」变成「腕」**——俯仰关节，与肩 / 肘同平面（用户 2026-10-16 确认）；
2. **三个关节的齿轮全部取消**，传动比一律为 **1**，`28/22`、`40/24`、`2.6` 在 V8 上都不存在；
3. **转盘的增速与承重轴系一起消失**，所以 V7 那张表里「输出扭矩 ×0.385、由金属轴 + 625 轴承承重」的整行说明**失效**；
4. **行程全部需要重新标定**——V7 那三个角度是齿轮比与模型姿态反推出来的，V8 换了臂长（上臂 **140** / 小臂 **145.5 mm**）与传动形式，必须逐关节重量可用角度。

**不存在的关节（重要，别按 6 轴想）**：

- **底座不回转** —— 没有第 4 个回转轴，三工位换位靠 **J3 腕关节**完成（V7 是靠转盘）。
- **有腕关节（V8 新增）** —— 三爪直接装在与肩 / 肘同平面的**俯仰腕**上，**靠腕转 120° 换位**；它既不是底盘回转，也不是连续姿态自由度。
- **腕只是「工位选择器」，不是「姿态度」** —— 三只爪 120° 均布，腕位只有**三个离散取值**，所以**逆解仍按平面 2 连杆做**（见「逆解与腕关节换位」一节），**不是 3 自由度连续逆解**。

**腕关节的硬限制**：**只能按有限角度往返，不允许连续累积旋转**。V7 列的两条原因里，**「齿轮组没有无限位设计」在 V8 上已不成立**（无齿轮），**只剩线束一条**——三只爪与 MG90S 的线要从臂根一路走到爪上，腕每转一次都在累积扭转，必须做往返管理（见「动作序列与状态机」的回转门）。

### 限位来源与优先级

`软限位（程序）` ∩ `机械限位（结构挡住）` ∩ `舵机自身行程`，三者取**最紧**的那一组。

- **舵机自身行程**：MG996R「180°」是型号标称，**实际有效转角尚未确定**（V7 设计输入原文如此）。标称 180° 的舵机常有 ±10° 以上的脉宽盲区，必须实测。
- **机械限位**：V7 的 CAD 只做了离散姿态检查，**未做连续扫掠证明**，所以不能假定"CAD 没撞 = 实车不撞"。
- **软限位**：写在配置表里，是唯一能在跑的过程中保护机构的一层。

## 角度映射与脉宽标定

> 完成时间点：2026-10-14　｜　状态：**已定**

### V7 给出的名义映射（**V8 已作废，仅作历史**）

令 `s` = 肩角、`e` = 肘相对角、`d` = 盘面世界角（单位：度）。V7 模型初始姿态为 **肩 0° / 肘相对角 156° / 盘面世界角 158°**，当时一组可行的**名义**指令映射是：

```
肩舵机角   = 175 − s × 28/22
肘舵机角   = 10  + (156 − e) × 40/24
转盘舵机角 = 50  − (d − s − e) / 2.6
```

**性质说明**（V7 源文件自己也强调过）：这三条是**运动学映射示例**，不是可直接烧录的控制程序；系数 `28/22`、`40/24`、`2.6` 是**齿轮传动比**，偏移（175、10、50、156）是**按模型姿态凑出来的**；必须装舵盘时对正相位，再按实际方向、脉宽和端点标定。

### V8 的映射：三个系数全部变成 1

**V8 把三个关节的打印齿轮组整体拿掉**（舵盘直驱），所以传动比项**全部消失**：

```
舵机角 = 关节角          （传动比 1:1）
肩舵机角 = 肩角 s          （原 ×28/22）
肘舵机角 = 肘角 e          （原 ×40/24）
腕舵机角 = 腕角 w          （原 /2.6）
```

**⚠ 但偏移量与方向不能照抄 V7 的 175 / 10 / 50 / 156**——那四个数是按 V7 的模型初始姿态（肩 0°、肘 156°、盘面 158°）凑出来的，而 V8 换了臂长（上臂 140 / 小臂 145.5 mm）、取消齿轮、新增腕，**初始姿态与零位全部要重新定义**。所以 V8 的映射表在标定之前是：

| 关节 | 传动比 | 偏移（零点） | 方向 invert | 状态 |
| --- | --- | --- | --- | --- |
| J1 肩 | **1** | `<待标定：0° 端脉宽>` | `<待标定：180° 端脉宽>` | 未标定 |
| J2 肘 | **1** | `<待标定：0° 端脉宽>` | `<待标定：180° 端脉宽>` | 未标定 |
| J3 腕 | **1** | `<待标定：0° 端脉宽>` | `<待标定：180° 端脉宽>` | 未标定 |

**这一处是 V8 真正的好消息**：V7 里「齿轮比 → 舵机角」这层换算容易算错，而且齿轮背隙会直接变成末端定位误差；V8 把这一层整个删掉了，**舵机角就是关节角**，标定表直接就是控制表。

**仍需保留的一条**（V7 原文）：**盘面世界角 `d` 不能直接当腕舵机角**——整车平移用于对准，换位还要与臂俯仰 `s、e` 合并计算（V7 的 `d − s − e` 结构在 V8 上仍成立，只是系数从 `/2.6` 变成 `×1`）。

### 标定流程（每个关节都走一遍）

1. **找机械中位**：把该关节摆到结构上的中位，手扶住，逐渐改脉宽直到舵机不较劲；记下这个脉宽（理论 1500 µs，实际常偏 20–80 µs）。
2. **测两端**：从小脉宽缓慢加大，记录**机构刚碰到限位**与**舵机开始叫（堵转）**之间的窗口；软限位取窗口内侧留 3–5° 余量。
3. **定方向**：只发一次"目标角大于当前角"的指令，看机构往哪边走，决定 `invert` 位。
4. **写回配置表**：把「中位 / 下限 / 上限 / 方向 / 软限位」五元组写进上面的表，并在代码里用同一张表（**不要在代码里散落魔法数字**）。
5. **复测**：按 1→2→3 的顺序各走一遍全程，确认无堵转、无干涉、无掉位。

### 脉宽与角度的关系（为什么不能只靠线性公式）

参考项目的做法是**逐关节手工标定**，每个关节一个不同的线性式，而且还留着一段"统一 +90"的旧写法被注释掉——这说明它也是**从理论式退化成逐关节凑**的。教训：**舵机的脉宽-角度关系不是全行程理想的线性**，靠近两端的斜率常常变化。我们的做法是：**线性式只用来算初值，最终以标定表为准。**

⚠ 另外注意：MG996R 标称 180° 常用 **500–2500 µs** 对应 0–180°，而不少舵机实际是 **1000–2000 µs**——**两者差一倍行程**。上电前必须确认，否则第一次测试就可能把机构顶到限位。

## 逆解与腕关节换位

> 完成时间点：2026-10-14（V7）／2026-10-17（V8 修订）　｜　状态：**已定**

### 为什么 V8 仍然不需要「扫掠取中间解」

很多参考项目（包括我们登记的 `visual_robotic_arm-master`）是**六轴 / 四自由度含腕**，逆解不唯一，需要「扫一个腕部角度之和、在所有合法解里**取中间解**」这种技巧。

**V8 不是这种问题。** 但它比 V7 需要多说一句——因为 V8 **多了一个腕关节**，很容易误以为逆解变复杂：

| 关节 | 性质 | 是否参与逆解 |
| --- | --- | --- |
| J1 肩、J2 肘 | **平面 2 连杆** | ✅ 唯一要解的两个 |
| **J3 腕** | **离散工位选择器**（三只爪 120° 均布，只有三个取值） | ❌ **不参与逆解**——它决定「用哪只爪去够」，不是「把末端摆成某个姿态」 |

所以 V8 的逆解是：**先定腕位（三选一，离散枚举）→ 再用平面 2 连杆闭式解把该爪的指尖送到目标点。** 这与 V7「先选三工位、再解平面 2 连杆」是同一套结构，只是换位机构从转盘换成了腕。

| 环节 | 数学性质 | 做法 |
| --- | --- | --- |
| 腕位选择 | **离散枚举** | 3 个工位里挑「当前姿态可达且转动行程最短」的一个；**腕角只有 3 个合法值**，不做连续求解 |
| 手爪到目标点 | **平面 2 连杆逆解** | 闭式解，**只有两组解（肘上 / 肘下）**，取让机构远离限位的那一组（一般是「肘上」） |
| 腕位与臂的耦合 | **耦合补偿** | 换位时的盘面世界角 `d` 必须与臂俯仰 `s、e` **合并计算**，**不能只检查 120° 间隔**（V7 原文明确警告，V8 继续适用） |

**结论：V8 仍然不需要「扫掠取中间解」。** 参考项目那套技巧之所以值钱，是因为它的腕是**连续姿态度**，导致解不唯一；我们的腕是**离散三工位选择器**，自由度并没有真正增加。**这是我们方案的一个真实优势，值得写进文档。**

> **反向提醒**：如果给 V8 的腕做连续控制（比如用它调爪的俯仰角），它就**立刻**变成真正的 3 自由度问题——逆解不唯一、需要取中间解那一套。**现在不要这么做**：腕的职责只有「换一只爪」。

### 两种实现路线

| 候选 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| **离线计算动作表**（把常用取物点预先解算成「腕位 + 关节角序列」，烧进程序） | ① 简单、可复现（同输入永远同输出）；② 不占 CPU；③ 比赛场地固定，常用点位数量有限；④ **6 个舵机没有位置反馈，开环控制下离线表最稳** | 换点要重算重烧 | ✅ **首选** |
| 在线逆解（每帧算） | 任意点可达 | ① 需要三角函数库与浮点开销；② 现场调试困难；③ 一旦算错直接顶限位 | ⚠️ 作为补充（少量动态点） |

**不可达时怎么办（必须显式处理）**：平面 2 连杆逆解在目标超出臂长时不成立。**必须判断「无解」并拒绝执行**，而不是给出一个越界的「最接近解」——越界解会让舵机顶限位堵转，电流飙升拉低 5 V，主控复位；而手册规定**一方全部机器人 1 分钟内没有任何运动或机构活动即结束对局**，复位在这条规则下等于直接输掉这一局。

### 腕关节换位的动作原则（V7 的转盘原则，逐条映射过来）

1. **一只爪对齐 → 合爪 → 退离 → 移到净空 → 再换位**（不在夹着东西的姿态下硬转）；
2. **悬挂块必须沿杆退到自由端之后再换位**——**完全脱杆后才能动腕**；
3. 悬挂块允许通过**整车后退**沿杆退出；
4. **腕只按有限角度往返（一次 120° 量级），不允许连续累积旋转**——V8 已无齿轮组，这一条现在**只受线束约束**，但线束反而是更容易被忽略的那一条。

## 舵机供电与浪涌

> 完成时间点：2026-10-14　｜　状态：**已定**（供电拓扑已定；模块电流与轨压跌落仍需实测，见本节 §7 与文末「待标定 / 待填清单」）

### 1. 目标与验收标准

- 满足手册：**18650 电池、每台机器人仅允许 1 个供电模块、供电模块额定电压 ≤ 7.4 V**；
- 满足手册电源管理规范：**必装官方无线继电器**，能在 10 m 内被单独遥控器切断底盘电源；
- 6 个舵机 + 4 个电机 + 主控同时工作时，**5 V 轨不跌落、主控不复位**；
- 舵机堵转时不产生"电流飙升 → 母线塌陷"的连锁。

### 2. 先把规则读死：什么叫"1 个供电模块"

手册的定义非常具体：

> **供电模块定义为有且仅有一个输出接口**（如 XT30 接口、一对杜邦线头等）的供电装置。如无线继电器与电池组前存在延长线或转接线，则按照**离电池组最近的一端**计算接口数量。**该供电装置的内部拓扑结构不会影响对其数量的判定。**

这句话有两个杀伤力：

1. **"内部拓扑不影响数量判定"**——你不能把两个并联的降压模块说成"一块电源板"。**两个模块就是两个模块。**
2. **"有且仅有一个输出接口"**——如果一块模块引出两路输出（一路 5 V 给逻辑、一路 6 V 给舵机），那它**有两个输出接口**，也可能被算成两个。

**直接后果**：V6/V7 源文件里那句「**6 只舵机独立供电**」如果落地成"再加一个独立 UBEC/BEC"，就是 **2 个供电模块 → 违规**。

> **现行决定（2026-10-14 合规审核后）**：不采用任何独立 BEC/UBEC。供电链固定为 **2×18650 7.4 V → 唯一的 Mini 降压模块 5V → 舵机与主控**，浪涌靠「入口大电容 + 舵机/电机统一错峰调度器 + 堵转检测」处理。若确需 6 V 给舵机，唯一合规路径是把降压做进**自制 PCB**，且须先取得组委会书面口径。


### 3. 技术选型对比

| 候选 | 拓扑 | 合规性 | 风险 | 结论 |
| ---- | ---- | ---- | ---- | ---- |
| **A. 单 5 V 轨（全车一个模块）** | 2S 18650（7.4 V 标称 / 8.4 V 满电）→ **1× 官方 Mini 降压模块 5V** → 5 V 供 STM32 + 6 舵机 + 4 电机 | ✅ **1 个供电模块** | ① **舵机在 5 V 下扭矩明显小于 6 V**，而肩关节余量本来就紧；② 单模块的**持续/峰值电流能力未知** | ⚠️ **作为基准方案，必须实测** |
| **B. 电机直挂电池 + 模块只供 5 V** | 电池 → 电机（DRV8833 直接吃 7.4 V）；同一电池 → 1× 模块 → 5 V 舵机+逻辑 | ⚠️ 仍算 1 个模块 | **TT 马达标称 DC3–6 V，7.4 V 是超压**；寿命与发热未知 | ❌ **不推荐**（超压不在规则豁免里，且是可靠性风险） |
| **C. 加第二个 UBEC/BEC 给舵机** | 电池 → 模块 A（逻辑 5 V）＋ 模块 B（舵机 6 V） | ❌ **2 个供电模块，违规**——这一条属于**通用技术规范**，**对所有分组一律适用**，与物资表无关（本队已确认为**新生组**，表外件可自购，但这条约束不因此放开） | —— | ❌ **不采用** |
| **A+. 单 5 V 轨 + 入口大电容 + 严格错峰** | 同 A，增加 ≥2200 µF 低 ESR 入口电容 + 舵机/电机统一调度器 | ✅ **1 个供电模块** | 需要实测验证 | ✅ **推荐落地顺序：先 A+，把电流作为 P0 实测项** |

> **合规替代思路**：手册把「**自制 PCB**」也列为豁免项。把降压电路做进**自己设计的 PCB**，有可能被认定为"自制 PCB 的一部分"而不是"外购供电模块"——**但手册说"内部拓扑不影响数量判定"，这句话是否也覆盖自制 PCB，必须向组委会书面澄清**（已列入下方待澄清问题）。

### 4. 实现过程：电流预算（这是本节的核心）

**峰值电流估算**（下列均为典型值估算，**必须逐路实测确认**）：

| 负载 | 数量 | 空载/只 | 堵转或启动峰值/只 | 小计峰值 |
| ---- | -- | ---- | ---- | ---- |
| MG996R（肩 / 肘 / **腕**） | 3 | 约 100–200 mA | **约 2.5 A**（6 V 堵转量级） | **约 7.5 A** |
| MG90S（三爪） | 3 | 约 50–100 mA | 约 0.7 A | 约 2.1 A |
| TT 马达 ×4 | 4 | 约 150 mA | 约 1.2 A（堵转） | 约 4.8 A |
| STM32 + PS2 + 模块自身损耗 | — | 约 100 mA | — | 约 0.1 A |
| **不调度时的最坏合计** | 10 | — | — | **约 14.5 A** |

**这个数字远超任何一颗 Mini 降压模块的能力。** 所以：

- **必须做电流调度**：舵机与电机**共用同一个调度器**分时动作（不能各写各的），加斜坡限速，禁止"6 个舵机 + 4 个电机同时满速启动"；
- **必须有入口大电容**吸收瞬时浪涌；
- **必须实测模块能力**：从物资表买到的 Mini 降压模块，其**持续电流与峰值电流是未知量**，须用钳流表逐路实测；
- **舵机功率电流不得经过面包板与杜邦线**（V6/V7 已明确）——走独立粗线与端子。

### 5. 遇到的问题与解决

| 现象 | 定位过程 | 根因 | 对策 |
| ---- | ---- | ---- | ---- |
| **肩关节余量不足**（V7 的设计阶段估算，非实测；**V8 需重算**） | 按实心 PLA 1.24 g/cm³、MG996R 55 g、MG90S 15 g、每套爪假定 30 g、方块 11.29 g、**齿轮效率 75%** 估算 | 肩舵机最大静态需求 **约 8.60 kgf·cm**，MG996R **6 V 标称堵转 11 kgf·cm**——名义比值仅 **1.28×**，而**堵转扭矩不是持续允许扭矩**；若按「唯一供电模块 5 V」供电，可用扭矩还要再降一档。该估算**未计**线束、完整紧固件、加速冲击与实际摩擦。 | **不得靠提高供电电压补偿**（V7 原文）。合规出路：**减轻臂端重量 → 调整取物距离 → 设计助力**。**V8 走的正是第一条**（取消转盘 + 齿轮 + 承重轴系）。另需注意：V8 **直驱后 75% 的齿轮效率项消失**，这一项在 V7 的 8.60 里是**放大**需求的（÷0.75），所以直驱的需求扭矩未必高于 V7；**但臂长也变了（140 / 145.5 mm），必须重算，不能沿用 8.60** |
| **现象（待实测）**：舵机动作时主控复位 | 对照 `04` 的「四路电机同时启动时 MCU 复位」 | 疑为浪涌拉低 5 V | 入口大电容 + 错峰 + 实测轨压 |

## 动作序列与状态机

> 完成时间点：2026-10-15　｜　状态：**已定**

### 单次取物—卸料的动作链

```
IDLE（收拢姿态）
  → 展开（若初始折叠）
  → 对准：底盘平移 + J1/J2 到位
  → 合爪（对应工位的那只 MG90S）
  → 抬升 / 退离（先离地，再离开杆）
  → 移到净空（离开储仓与臂的自干涉区）
  → [需要换爪时] J3 腕关节换位（三工位离散，每次约 120°）
  → 卸料：移到储仓右侧上方 → 张爪 → 方块落仓
  → 回位（转回下一个待取工位）
```

### 硬性门控（违反即可能损坏机构或违规）

| 门控 | 条件 | 违反后果 |
| ---- | ---- | ---- |
| **脱杆门** | 悬挂块**完全脱杆**才允许 J3 换位 | 杆与爪干涉，可能损坏机构 |
| **净空门** | 夹持状态下**先移到净空**才允许换位 | 自干涉 |
| **回转门** | J3 只做**有限角度往返**，禁止连续累积旋转 | 线束绞断（V8 已无齿轮组，此门现在只受线束约束） |
| **堵转门** | 任一舵机持续堵转超过阈值时间 → 停止该动作并回退 | 电流飙升 → 母线塌陷 → 复位 |
| **不可达门** | 逆解无解时**拒绝执行**，不输出越界角 | 顶限位堵转 |

### 与手册规则的对应

- 「任一验证不通过 → 回到机构修改」这条闭环，在本文件里体现为：**堵转/复位/掉位这三类现象一旦出现，先改机械（减重、改取物距离、加助力），不许只改软件参数硬顶。**
- 三只夹爪**独立驱动、独立保持、独立释放**（V7 设计输入），所以状态机要能表达"持有 1 块 / 2 块 / 3 块"三种在途状态，**不能假设它们总是一起动作**。

## 安全与故障处理

> 完成时间点：2026-10-15　｜　状态：**已定**

| 故障 | 检测手段 | 处理策略 |
| ---- | ---- | ---- |
| **舵机堵转** | 舵机无位置反馈 → 用**动作超时**间接判断（发指令后 N ms 未到达下一个序列点即认为异常）；或经 AISEN 采样电流 | 立即停止该关节输出、回退到上一个安全姿态、点亮状态指示 |
| **PS2 失联** | 连续若干轮收不到手柄数据包 | **超时停车**（沿用 `04` 的结论：不失能、不保持上一指令、不原地旋转找信号） |
| **主控复位** | 上电标志 / 看门狗复位标志 | 复位后**先回收拢姿态再接受指令**，避免带着未知姿态继续动作 |
| **无线继电器断电** | 裁判遥控触发（不经过 MCU） | 硬件直接切断底盘电源；**赛前必须实测 10 m 内可断**，赛前把断电遥控器交裁判 |
| **上电自检** | 启动流程 | ① 读配置表；② 6 路 PWM 先写中位；③ 检查电池电压（2S 低于阈值报警）；④ 机构归位到收拢姿态；⑤ 等待手柄连接 |
| **掉电位置保持** | —— | 位置舵机断电自锁，满足手册「任意非初始状态保持相对静止」；**但自锁不等于能抗外力**，检录落体测试时仍可能被冲击带位，需实测 |

**手册指标自查**：「同一台机器人完成至少三个舵机的转动，且**确保其可动机构能够在任意非初始状态下保持相对静止**」——我们的 6 个舵机都是位置舵机，断电自锁；验收时要在**任意非初始状态**下逐一检查，而不是只检查收拢态。
